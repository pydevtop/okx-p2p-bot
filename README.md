# OKX P2P Bot — P2P Trading Automation & Telegram Order Management

**OKX P2P Bot** is a Python-based automation tool for monitoring and managing P2P trading activity on the OKX cryptocurrency exchange.

The bot helps P2P traders monitor buy and sell orders, receive instant order notifications, synchronize OKX P2P chat with Telegram, confirm payments, upload payment receipts, notify counterparties, and release crypto directly from Telegram.

Instead of constantly switching between the OKX website, P2P orders, order chat, and Telegram, traders can manage the most important parts of their **OKX P2P workflow from a single Telegram bot**.

### Telegram P2P Order Management

The bot provides quick access to the main P2P order actions directly from Telegram:

- Monitor OKX P2P buy and sell orders
- Receive new P2P order alerts in Telegram
- View order amount, price, payment method and other details
- Synchronize OKX P2P order chat with Telegram
- Receive counterparty messages directly in Telegram
- Reply to OKX P2P chat messages from Telegram
- Mark an order as paid
- Upload and send payment receipts
- Remind the seller that payment has been completed
- Release crypto directly from Telegram
- Track important P2P order actions from one interface

This creates a convenient workflow for active P2P traders who need to react quickly without constantly switching between OKX pages and Telegram.

## OKX P2P Chat Synchronization with Telegram

The bot can synchronize **OKX P2P order chat with Telegram**, allowing traders to communicate with counterparties without keeping the OKX order page open.

New P2P chat messages are forwarded directly to Telegram.

Traders can reply to these messages from Telegram, keeping order notifications, payment actions, and counterparty communication together in one interface.

This is especially useful when managing multiple P2P orders simultaneously.

## Payment Confirmation from Telegram

After completing a payment, the trader can mark the corresponding **OKX P2P order as paid directly from Telegram**.

This reduces unnecessary switching between Telegram, payment applications, and the OKX P2P order interface.

## Payment Receipt Upload

Payment receipts can be uploaded and sent directly through the Telegram bot.

This makes it easier to provide payment confirmation to the counterparty while keeping the entire order workflow in one place.

## Seller Payment Reminder

After payment has been completed, the bot provides a quick action to remind the seller that the funds have already been sent.

This helps the counterparty notice the completed payment and proceed with the crypto release.

## Release Crypto from Telegram

For applicable sell orders, the bot provides a **Release Crypto** action directly in Telegram.

This allows another important OKX P2P order action to be performed without returning to the OKX interface.

> **Security notice:** Always verify that the payment has actually been received before releasing cryptocurrency.

## OKX P2P Trading Automation

The bot can continuously monitor the **OKX P2P marketplace** according to parameters configured by the trader.

When a matching offer appears, the software can react according to the active task and notify the user through Telegram.

Multiple monitoring tasks can run simultaneously, allowing different cryptocurrencies, fiat currencies, payment methods, and price conditions to be monitored at the same time.

## Why Use an OKX P2P Telegram Bot?

Active P2P trading normally involves several repetitive actions:

**OKX P2P → New Order → Order Chat → Payment → Payment Confirmation → Receipt → Counterparty Communication → Crypto Release**

OKX P2P Bot brings these actions into a convenient Telegram-based workflow:

**New Order → Telegram → Chat → Payment Confirmation → Receipt → Reminder → Crypto Release**

The result is less tab switching, faster access to order information, and a more convenient workflow for everyday **OKX P2P trading**.

## Typical OKX P2P Workflow

1. Create a monitoring task in the Telegram bot.
2. Select the cryptocurrency.
3. Select the fiat currency.
4. Configure payment methods or banks.
5. Set the target price and task parameters.
6. Start monitoring the OKX P2P marketplace.
7. Receive an alert when a matching opportunity or new order appears.
8. Receive and reply to P2P chat messages through Telegram.
9. Confirm payment directly from Telegram.
10. Upload the payment receipt.
11. Remind the seller that payment has been completed.
12. Release crypto from Telegram for applicable sell orders.

The goal is to keep the most frequently used **OKX P2P order management actions in one Telegram interface**.

## Installation

### Requirements

- Windows 10 / Windows 11
- Python 3.x
- Telegram account
- Telegram bot
- OKX account

### 1. Create a Telegram Bot

To manage OKX P2P Bot through Telegram, create your own Telegram bot.

Detailed instructions:

https://py-dev.top/registering-telegram-bot

Add the resulting Telegram Bot API token to the configuration file.

Example:

```python
BOT_TOKEN = "YOUR_TELEGRAM_BOT_TOKEN"
```

#### 2. Install Python
Detailed instructions on how to install Python on Windows: https://py-dev.top/installing-python

Go to the settings of the bot itself

Go to the C drive folder:
In the folder of drive C: unpack the archive OKXP2PBot.zip

Go to the OKXP2PBot folder and click on the start.bat file to start the bot

After that, a menu for creating task (orders) will appear.

The bot contains OKX filters: When creating a task (order) for the purchase, you will have a choice of cryptocurrency (asset)

Choosing which currency to buy (fiat)

Payment methods (PayType) - you can specify an unlimited number

System requirements: Windows 10/11, Python 3.x.x
